Fonts

Atkinson Hyperlegible Next — designed by the Braille Institute of America for maximum legibility, including for low-vision readers. Used as the primary body and UI font. SIL Open Font License 1.1
Anois Lúil — by Gaeltacht Type. Used for Gaeilge and Irish-focused text in the site’s default multi-font layout.
Lexend — an optional reader-selected font designed to reduce visual stress and improve reading performance. SIL OFL 1.1
OpenDyslexic — an optional reader-selected typeface intended to help some readers with dyslexia. SIL OFL 1.1
Open Sans — an optional reader-selected humanist sans-serif by Steve Matteson. SIL OFL 1.1
Source Serif 4 — an optional reader-selected serif typeface by Frank Grießhammer for Adobe. SIL OFL 1.1
Atkinson Hyperlegible Mono — used for code samples and terminal snippets. SIL OFL 1.1

Badges & web-button graphics

Badges & web buttons — "88x31" web buttons from the web-1.0 era, sourced from 88x31.lol and An Lucas (Neocities). Classic 88×31 pixel graphics that have circulated freely across the web for decades.
"For The Badge" project-status badges (used on previous iterations of the site) — forthebadge.com.

Inspiration & references

The visual language of this site is a love letter to the late-1990s / early-2000s Mac web — iMac G3, iBook Clamshell, iBook G4, Mac OS 9.2, 10.0 Cheetah and 10.4 Tiger all sit somewhere in its DNA.
European Union Public License (EUPL) v1.2 — the underlying licence for the site source. The unofficial Irish translation hosted here is a derivative work for community use; the official EU text remains authoritative. Official EUPL 1.2 text.
WCAG 2.2 from the W3C — the accessibility target this site aims to meet (and exceed where practical). W3C WCAG 2.2.
